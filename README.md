# mssh — سورس نسخهٔ آزمایشی

پروژهٔ اندروید Kotlin / Jetpack Compose با رابط فارسی RTL، تم سرمه‌ای/طلایی و نشان M قرمز.

## وضعیت واقعی
کد مدیریت پروفایل رمزگذاری‌شده، اتصال SSH با رمز و بررسی اثرانگشت SHA256 کلید میزبان، VpnService، پل SOCKS محلی و موتور بومی HEV برای تونل TCP اضافه شده است. رمز SSH هنگام اتصال دریافت می‌شود و در پروفایل ذخیره نمی‌شود. اطلاعات ورود کاربر در این بسته تعبیه نشده است.

این پروژه هنوز کامپایل و روی گوشی آزمایش نشده است؛ این بسته سورس است، نه APK و نه VPN تأییدشده. UDP عمومی، اتصال مجدد خودکار، انتخاب برنامه‌ها، ورود npvt و Kill Switch پیاده‌سازی نشده‌اند. با قطع سرویس، اینترنت عادی برمی‌گردد. DNS، IPv6 و عدم نشت ترافیک نیازمند آزمون واقعی هستند.

## ساخت APK در GitHub
1. فایل ZIP را استخراج کنید.
2. تمام محتویات پوشهٔ MousaviVPN را در ریشهٔ مخزن خود قرار دهید؛ پوشهٔ مخفی `.github` را نیز حتماً منتقل کنید.
3. در GitHub به Actions → Build mssh alpha APK بروید و Run workflow را بزنید.
4. اگر ساخت موفق شد، از بخش Artifacts فایل `mssh-alpha-debug` را دانلود و استخراج کنید؛ APK داخل آن است.
5. اگر ساخت شکست خورد، لاگ مرحلهٔ خطادار برای رفع اشکال لازم است.

## ساخت محلی
JDK 17، Gradle 8.9، Android SDK 35 و NDK 27.2.12479018 لازم است. دانلود وابستگی‌ها نیازمند اینترنت است. Gradle Wrapper در بسته نیست؛ با Gradle نصب‌شده اجرا کنید:

```sh
gradle :app:assembleDebug --no-daemon --stacktrace
```

## اتصال آزمایشی
پروفایل SSH را اضافه کنید. هنگام اتصال رمز و اثرانگشت SHA256 کلید میزبان را وارد کنید؛ اثرانگشت را از مدیر سرور از مسیر قابل اعتماد بگیرید. اجازهٔ VPN اندروید را تأیید کنید. وضعیت نمایش‌داده‌شده تضمین امنیت یا دسترسی اینترنت نیست و باید روی دستگاه بررسی شود.

رمزی را که قبلاً در گفتگو ارسال کرده‌اید تغییر دهید. هیچ رمز یا کلید خصوصی را در GitHub منتشر نکنید.

## وابستگی بومی
سورس HEV و وابستگی‌های آن در `app/src/main/jni/hev` همراه فایل‌های مجوز موجود قرار دارند؛ هنگام توزیع، مجوزهای آن‌ها را رعایت کنید.
